Set up Phantom Cast as an OBS virtual camera in 5 minutes

The OBS virtual camera output (Premium add-on) lets the swapped feed appear as a normal webcam in any app — Twitch, YouTube Live, Zoom, Google Meet, Microsoft Teams, Discord, Slack huddles. Set up takes about five minutes.

Prerequisites

  • Phantom Cast 1.4.0+ with the Premium add-on active
  • OBS Studio 30+ installed (any operating system)
  • The Phantom Cast Virtual Camera driver (offered during installation; can also be installed later from Settings → Live output)

Step 1 — Enable live output in Phantom Cast

  1. Open Phantom Cast and load a project with your source identity.
  2. Switch to the Live tab.
  3. Pick your physical webcam under "Input device" and set the resolution / framerate (1080p30 recommended for streaming).
  4. Toggle Output to virtual camera on. The status indicator should turn green.

Step 2 — Add the virtual camera in OBS

  1. In OBS, in your scene, click + in the Sources panel → Video Capture Device.
  2. Name it "Phantom Cast" → OK.
  3. From the "Device" dropdown, choose Phantom Cast Virtual Camera.
  4. Set Resolution/FPS Type to Custom and pick 1920×1080 @ 30.
  5. Click OK. You should immediately see your swapped feed in the OBS preview.

Step 3 — Pipe to Twitch / YouTube / Zoom / etc.

From here it's normal OBS workflow:

  • Twitch / YouTube: Settings → Stream → key in your stream key → Start streaming.
  • Zoom / Meet / Teams / Discord: in the conferencing app's video settings, pick "OBS Virtual Camera" (or "Phantom Cast Virtual Camera" if you skip OBS).

Performance tuning

  • If you get dropped frames in OBS, lower the input resolution to 720p — the swap quality difference is negligible at streaming bitrates.
  • Enable NVENC as the OBS encoder so OBS isn't fighting Phantom Cast for the GPU's CUDA cores.
  • Use Windows "High performance" power plan; the difference is ~10% sustained fps.

Latency

Total added latency from camera capture to OBS preview is typically 80-120 ms on an RTX 3060 — imperceptible for chat / streaming, but worth knowing for time-critical applications. The on-screen "live offset" indicator shows it in real time.
