System requirements

Operating system

  • Windows 10 21H2 (build 19044) or Windows 11 — fully supported
  • macOS 14+ on Apple Silicon (M2/M3) — private beta
  • Ubuntu 22.04+ — planned H2 2026

RAM & disk

NVIDIA GPU compatibility

Phantom Cast needs compute capability 7.5 or newer (Turing / Ampere / Ada Lovelace / Blackwell). Older architectures fall back to CPU.

AMD & Intel GPUs

Phantom Cast 1.x is CUDA-only. AMD ROCm and Intel oneAPI backends are scoped for 2.x. Until then, AMD/Intel users get the CPU fallback path.

Driver baseline

  • NVIDIA driver ≥ 525.60 (CUDA 12 runtime requirement)
  • cuDNN 8.9 bundled with the installer — no separate install needed
  • TensorRT 10.0 bundled — required for the optional optimized inference path

OBS plugin compatibility

  • OBS Studio 28+ — supported
  • OBS Studio 30+ — recommended (better virtual camera latency)
  • Streamlabs Desktop — supported via shared OBS virtual camera driver
