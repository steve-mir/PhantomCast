## What is Phantom Cast

Phantom Cast turns a live webcam or 4K video into a different face — without uploading a single frame to the cloud. It is built for streamers, creators, and producers who care about privacy and performance.

- 30 fps live webcam swap on a discrete NVIDIA GPU
- 4K image and video export with face enhancement
- Virtual camera output that any conferencing or streaming app can pick up
- Frames, audio, and video never leave your machine — only license checks and version pings touch the network

## Quick start

1. Download the signed Windows installer from [phantomcast.space/download](https://phantomcast.space/download.html).
2. Run the installer and let it set up the runtime + first-run wizard.
3. Pick a source face, select your camera, and hit **Live**.

## System requirements

| Component | Recommended |
|-----------|-------------|
| OS        | Windows 10 / 11 (x64) |
| GPU       | NVIDIA discrete GPU with CUDA 12.x driver (525.60+) |
| RAM       | 16 GB |
| Disk      | 5 GB free |

CPU-only mode is supported but processing is significantly slower. Apple Silicon support is experimental.
