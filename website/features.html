Real-time webcam swap

Pick a face, hit start. Phantom Cast captures your webcam at 30 fps, runs it through CUDA inference, and outputs the swapped feed to an OBS virtual camera that any app can use as a video source.

  • 30 fps stable on RTX 3060 / 1080p · 60 fps on 4070 Ti
  • OBS virtual camera output with one click — works in Twitch, YouTube Live, Zoom, Meet, Teams, Discord
  • Frame buffer pre-warm so the first second isn't a flicker
  • Per-clip identity lock — face does not "drift" across long sessions

Hyperswap full-head mode

When the face-only swap looks like a mask, Hyperswap extends the inference region to include hairline, ears, and jaw silhouette. Slower, but indistinguishable in close-ups.

  • Full skull tracking with hair / ear / jawline blending
  • Trade-off slider: 1× (face only) → 4× (full head, slowest)
  • Best paired with GPEN-512 for film-grade close-ups

GPU diagnostics + automatic CPU fallback

No black-box "your GPU isn't supported" message. Phantom Cast tells you exactly which step of CUDA detection failed, what to do about it, and offers a CPU fallback so you can keep working while you fix it.

  • Per-step CUDA / driver / cuDNN / TensorRT diagnostics with copy-paste fixes
  • Automatic CPU fallback — never blocks the workflow
  • One-click "send diagnostic bundle" if you open a support ticket (no frames included)
By design

Privacy is the architecture, not a setting

There is no upload pipeline. There are no servers that could leak. Inference is local — full stop. The only network traffic Phantom Cast generates is licensing and version checks.

  • Zero frames transmitted, ever — verifiable by inspecting outbound traffic
  • License fingerprint is a composite SHA-256 — raw machine identifiers never leave the device
  • Optional offline mode disables every network call after activation
  • SOC 2-style audit logs available on request for B2B customers
