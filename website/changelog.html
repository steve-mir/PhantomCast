0.0.23

Latest
May 2026

Added

  • Hardware fingerprinting and license activation tool.
  • Friendly CUDA-missing reminder for post-install launches.

  • Two-tier subscription model with free and premium plans.
  • Background model download and verification at first launch.
  • Output pipeline with virtual camera and LUT support.

Fixed

  • Models directory handling for frozen builds.
  • Activation key prompt: reflects new pricing and subscription details.

Changed

  • Slimmed Windows installer below the GitHub 2 GB release-asset cap.
  • Build now ships CPU torch + system CUDA instead of bundling the full CUDA stack.
