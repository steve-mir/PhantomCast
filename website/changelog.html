1.4.2

Latest
May 6, 2026

Added

  • GPEN-512 face enhancement is now the default for all 4K exports.
  • Tray notification when a batch job completes.
  • Dashboard "Move license" rate-limit display (1 move per year).

Fixed

  • OBS virtual camera dropped to 24 fps when Windows changed power plans — now stays locked to 30 fps.
  • Hyperswap full-head: occasional jaw jitter on profile angles > 60°.
  • License heartbeat now retries with exponential backoff instead of failing fast on transient DNS.

Changed

  • Bumped CUDA runtime from 12.0 → 12.1; minimum NVIDIA driver is now 525.60 (was 520.61).

1.4.0
