Troubleshooting

Why your CUDA face-swap is running on CPU

If the FPS counter is below 10 fps and the inference badge says CPU, one of four things is wrong. They're listed in order of how often they're the culprit.

1. NVIDIA driver too old

Phantom Cast 1.4 requires NVIDIA driver ≥ 525.60. Older drivers don't ship the CUDA 12.1 runtime we depend on.

# Check from PowerShell
nvidia-smi | findstr "Driver Version"

Update from nvidia.com/Download. After the install completes, reboot before relaunching Phantom Cast.

2. Wrong GPU is being used

Laptops with both Intel/AMD integrated graphics and an NVIDIA dGPU often default to integrated. Force the dGPU:

  1. Right-click the desktop → NVIDIA Control Panel
  2. Manage 3D settings → Program Settings
  3. Add phantomcast.exe and set "Preferred graphics processor" to "High-performance NVIDIA processor"

3. CUDA toolkit was installed by something else and conflicts

If you have a system-wide CUDA toolkit installed (e.g., from a TensorFlow setup) at a different version than what we ship, the loader can pick the wrong DLLs. Phantom Cast bundles its own CUDA runtime, so the safe fix is to scope your PATH:

# Confirm what cudart.dll is being loaded:
where cudart64_12.dll

If the result points outside C:\Program Files\PhantomCast, remove that directory from PATH for your user (or move Phantom Cast's directory before it).

4. GPU is supported but lacks the SM the model needs

The bundled face-swap model needs compute capability ≥ 7.5 (Turing or newer). GTX 10-series cards (compute 6.x) will fall back to CPU. Full GPU compatibility list.

Send a diagnostic bundle

If none of the above fixes it, the app can package a diagnostic bundle for support to inspect. No frames are included — just driver versions, dxdiag output, GPU detection logs, and the last 200 lines of phantomcast.log.

  1. Settings → GPU diagnostics → Send diagnostic bundle
  2. Copy the resulting bundle ID and reference it in your support ticket.

Still stuck? Contact support — we triage GPU issues fastest because they're usually a 5-minute fix.
