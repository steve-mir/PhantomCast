Getting started

This walks you through installing Phantom Cast, activating your license, and running your first face swap. By the end you'll have an OBS-ready virtual camera output and a 1080p exported video to compare against.

1. Install

  1. Download PhantomCast-Setup-1.4.2.exe from /download.
  2. Verify the SHA-256 checksum against the value shown on the download page (instructions below).
  3. Run the installer. Accept the EULA. Choose whether to install the OBS virtual camera driver (Premium feature).
  4. Launch Phantom Cast. The first run will check for a CUDA-capable GPU and report what it found.

Verifying the installer

Code signing tells you the file came from us. Checksum verification additionally tells you it wasn't modified after we signed it.

# PowerShell
Get-FileHash -Algorithm SHA256 .\PhantomCast-Setup-1.4.2.exe

Compare the printed hash with the one on the download page. They should match exactly.

2. Activate your license

On first launch you'll see three options:

  • Start the 7-day trial — fully featured, output is watermarked.
  • I have a license key — paste the PC-XXXXX-XXXXX-XXXXX-XXXXX key sent to your email.
  • Buy a license — opens /checkout in your browser.
The license heartbeat needs internet on first activation. After that, the app works fully offline for up to 30 days between heartbeats.

3. Run your first swap

  1. Click + New project.
  2. Drag a source image (the face you want to swap in) into the source pane.
  3. Drag a video file (or click "Use webcam") into the target pane.
  4. Click Preview. You should see live inference; the FPS counter should read ~30 on a CUDA-capable GPU.
  5. Click Export to render the swapped clip to disk. Default output: ~/Videos/PhantomCast/<project>.mp4.

4. Common gotchas

  • Source image quality matters. Use a sharp, well-lit, near-frontal photo. Avoid sunglasses, heavy filters, or extreme angles.
  • Match the lighting if you can. Phantom Cast does color match per pair, but big mismatches between source and target lighting are still visible.
  • FPS counter says "CPU"? See GPU troubleshooting — it's almost always one of three driver-side issues.
